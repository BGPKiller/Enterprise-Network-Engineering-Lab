# Enterprise Network Engineering Lab

## Overview

This repository documents my hands-on enterprise networking lab work as I build and strengthen practical network engineering skills.

The current focus is Cisco Enterprise networking technologies aligned with my CCNP Enterprise 350-401 ENCOR studies. The lab will evolve over time as additional networking, security, automation, multi-vendor, and cloud technologies are introduced.

## Current Focus

- Cisco CCN Enterprise 350-401 ENCOR
- Layer 2 and Layer 3 networking
- IPv4 and IPv6
- OSPF and BGP
- Network services
- Network security
- Network assurance and troubleshooting
- Network automation fundamentals

## Objectives

- Build enterprise-style network topologies
- Configure and verify networking technologies
- Develop systematic troubleshooting skills
- Document configurations and design decisions
- Record problems, root causes, and resolutions
- Create a technical portfolio demonstrating practical network engineering experience

## Repository Structure

As the lab develops, this repository will contain:

- 'labs/' - Individual lab exercises and scenarios
- 'configs/' - Device configurations
- 'diagrams/' - Network topology and architecture diagrams
- 'docs/' - Design notes, addressing plans, and technical documentation
- 'troubleshooting/' - Incident scenarios, root-cause analysis, and resolutions
